# ブルアカ総力戦・大決戦ツール集

ブルーアーカイブの総力戦・大決戦向けの計算ツールです。

- **ダメージシミュレータ**: 攻撃カードの合計ダメージ分布と、目標ダメージの通過確率を計算
- **足切りライン最適化**: チェックポイントでリセットする運用の最適な足切りラインを計算
- **スキル順探索(β版)**: 使いたいスキル順を満たす開始スキル設定を全探索

使い方は [docs/manual.md](docs/manual.md) を参照してください。

## 起動

```sh
uv sync
uv run python main.py
```

ブラウザで http://localhost:8050 を開きます。
