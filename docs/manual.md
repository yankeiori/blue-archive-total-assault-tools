# ブルアカ総力戦・大決戦ツール集 利用マニュアル

## 概要

ブルーアーカイブの総力戦・大決戦等において、複数の攻撃カードによる**合計ダメージの分布**を計算し、目標ダメージの**通過確率**を算出するツールです。

ダメージのレンジ（会心・非会心の上下限、Hit数、会心率、回避率）は、**[Schale DB](https://schaledb.com/) のダメージ計算ツール**で得られた値をそのまま入力する想定です。Schale DB はダメージ減衰を考慮済みのため、後述の「減衰考慮済み」モードのまま使えます。ダメージ表示テキストの貼り付けによる自動取り込み（セクション6）も Schale DB の表示形式を対象としています。

このツールには3つのページがあります。

- **ダメージシミュレータ**: カードを並べて合計ダメージ分布と通過確率を計算します。
- **足切りライン最適化**: 同じ攻撃列を使い、複数チェックポイントでリセットする運用の**最適な足切りライン**を計算します。
- **スキル順探索(β版)**: 使いたいスキル順（手順）を満たす**開始スキル設定**を全探索します。

## 2. サイドバー設定（ダメージシミュレータ）

### 計算方式

| 方式 | 説明 |
|---|---|
| **COS法（準厳密・推奨）** | 特性関数のフーリエ余弦級数反転＋原子分離(DP)で、分布・通過確率を**直接かつ準厳密**に計算します。乱数を使わないため結果が安定し、低確率（深い裾）の通過判定も信頼できます。 |
| **モンテカルロ** | 乱数サンプリングによる従来方式。比較・確認用に残しています。サンプル数が有限なため、低確率域はばらつきます。 |

通常は **COS法** のままで構いません。同じカード設定なら両者の分布・期待値はほぼ一致し、COS法の方が滑らかです。

### HP依存ダメージ

ミカ・フィーナのように、与ダメージが**敵の現在HPに比例する倍率**を持つキャラを扱うモードです。

| 設定 | 説明 |
|---|---|
| **なし（合計＝和モデル）** | 各ヒットのダメージを単純合計する通常モデル。 |
| **あり（ミカ型。カード別に混在可）** | 倍率が現在HPに線形依存するモデル。HP満タン時の倍率(R1)・HP0時の倍率(R0)・敵の最大HP・開始時HPを入力します。 |

「あり」を選ぶと入力欄が表示されます。倍率は現在HP $H_n$ に対し `倍率 = (R1−R0)/最大HP × H_n + R0` で線形に変化します。

> ⚠ **HP依存カードのダメージ欄には「HP0時のダメージ」を入力してください。** 入力値に現在HPに応じた倍率（R0〜R1）が掛かる仕組みのため、満タン時や現在HPでのダメージ表示をそのまま入力すると倍率が二重に掛かり、正しく評価できません（R1>R0 のミカ型なら過大、R1<R0 の瀕死特効型なら過小になります）。

さらに、各カードの **「HP依存」チェック** で、そのカードのダメージがHP依存か通常かをカード単位で指定できます（初期値はチェックあり＝HP依存）。

- 全カードがHP依存 → 従来どおり**積モデル**（COS法）
- HP依存カードなし → **和モデル**
- 両方が混在 → **混在モデル**（同型連続ブロックごとに厳密な分布を求め、グリッドDPで合成）

混在時は「通常ダメージを先に入れるとHPが減り、後続のHP依存ヒットの倍率が下がる」効果（順序依存）も正しく計算されます。ミカ＋通常アタッカー編成のような構成はカードの並び順どおりに評価されるため、実際の攻撃順に並べてください。足切りライン最適化は積モデル・混在モデルの両方に対応しています。

### ダメージ生成モード

| モード | 説明 |
|---|---|
| **減衰考慮済み（推奨）** | 入力するダメージ値は減衰適用後の値。Schale DB など減衰を考慮済みのツールの値をそのまま入力できます。 |
| **減衰考慮前** | 入力するダメージ値は減衰適用前の生ダメージ。内部で減衰関数が適用されます。 |

Schale DB の値を使う場合は「**減衰考慮済み**」のままにしてください。

### 安定値（全体設定）

サイドバーの全体設定として入力し、全カードに共通で適用されます。

ダメージが大きいキャラでは、表示される最大ダメージが**減衰上限(10,966,999)で頭打ち**になり、本来の最大ダメージが分からなくなることがあります。このとき**安定値**を入力すると、信頼できる**最小ダメージ**から本来の最大ダメージを逆算します。

- 関係式: 減衰前の最小ダメージ ＝ 減衰前の最大ダメージ × `(1 − 1/(1 + 0.001 × 安定値) + 0.2)`
- これを解いて `減衰前の最大 ＝ 減衰前の最小 ÷ 比率` を求め、上限に張り付く分（上限到達分）を確率分布へ正しく反映します。
- **最大ダメージが上限未満なら安定値は無視され**、通常どおり入力値がそのまま使われます。未入力でも従来動作のままです。

## 3. 目標ダメージ・一括設定（カード一覧の上部）

達成したい合計ダメージを入力します。設定すると：

### 一括設定

全カードの会心率・回避率をまとめて設定します。

1. 会心率(%)と回避率(%)を入力
2. 「**一括適用**」ボタンを押す → 全カードに反映

## 4. ダメージカード

各攻撃カード（EXスキル・NSなど）のダメージ情報を1枚ずつ入力します。

### 入力項目

| 項目 | 説明 |
|---|---|
| **会心ダメージ下限 / 上限** | 会心発生時のダメージ範囲 |
| **非会心ダメージ下限 / 上限** | 非会心時のダメージ範囲 |
| **Hit数** | そのカードの攻撃ヒット回数 |
| **会心率 (%)** | 会心が発生する確率（カード個別に設定可能） |
| **回避率 (%)** | 敵が回避する確率（カード個別に設定可能） |
| **敵の数** | Hit数に掛けて総ヒット数を算出します。全体攻撃などで複数体に同時に当たる場合に 2 以上を指定します（通常は 1）。 |

> ※ **安定値**はカードごとではなく、サイドバーの全体設定で入力します（セクション2）。

### 操作

| 操作 | 方法 |
|---|---|
| カードの追加 | 「**+ ダメージ追加**」ボタン |
| カードの複製 | カード右上の「**📋**」ボタン（同じパラメータ・備考のカードが直後に追加されます） |
| カードの削除 | カード右上の「**✕**」ボタン（最低1枚は残ります） |
| カードの並べ替え | カード左上の「**⠿**」ハンドルをドラッグ＆ドロップ |
| メモの記入 | カード上部の備考欄に自由にテキストを入力 |

## 5. 入力の保存 / 読込（JSON）

カード一覧上部の「**💾 入力の保存 / 読込**」パネルで、現在の入力一式をファイルに保存・復元できます。

| 操作 | 方法 |
|---|---|
| エクスポート | 「**⬇ エクスポート (JSON)**」ボタン → 全カード・全体設定・足切りライン最適化の設定を JSON で保存 |
| インポート | 「**⬆ インポート**」エリアに JSON をドロップ、またはクリックして選択 |

- 保存される内容: 各カードのパラメータ（HP依存チェックを含む）と備考、全体設定（会心率・回避率・計算方式・HP依存・ダメージ生成モード・安定値・目標ダメージ）、足切りライン最適化のチェックポイント／区間ごとの所要時間。古いJSON（HP依存チェックなし）を読み込んだ場合は全カード「HP依存」扱いになります（従来と同じ挙動）。
- インポートすると足切りライン最適化の足切り設定（チェックポイント・区間ごとの所要時間）も復元されます。

## 6. テキストからカード自動生成

ダメージ表示の**テキストをコピー＆ペースト**してカードを自動生成できます。カード一覧上部の「**📝 テキストからカード生成**」パネルを使います。

| 操作 | 方法 |
|---|---|
| テキストから取り込み | テキスト入力欄にダメージ表示を貼り付け →「**テキストから取り込み**」ボタン |

ヒット行・ダメージ行・「会心」行が改行で分かれた、以下のような形式に対応します。

**一般（通常 + 会心）の例:**

```
ヒット1-2 (165.33%)
18,164 - 25,247
会心
35,239 - 48,979
ヒット3 (1322.61%)
145,315 - 201,977
会心
281,910 - 391,835
```

**確定会心 / 確定非会心（ダメージ1行のみ・「会心」行が続かない）の例:**

```
ヒット1-3 (415.83%)
24,893 - 31,980
ヒット4 (1524.72%)
91,276 - 117,259
```

- 「ヒットN-M」からヒット数を、続くダメージ行から通常レンジを、「会心」行の次のダメージ行から会心レンジを読み取ります。括弧内の倍率(%)は備考に記録されます。
- **「会心」行が続かない**ヒットは、**確定会心**（会心率100%）として取り込みます。実際には**確定非会心**だった場合は、生成後にそのカードの会心率を `0` に修正してください。
- 同じダメージ値が連続するヒットは1枚のカードにまとめ、Hit数を合算します。
- **HP依存**の表示（現在HP等）を含むテキストを検出すると、サイドバーのHP依存モードを自動でONにします。
- 取り込み結果は必ず目視で確認してください。

## 7. シミュレーション実行

1. 各カードのダメージ情報を入力
2. 目標ダメージを設定（任意）
3. 「**シミュレーション実行**」ボタンを押す

### 結果の見方

- **分布グラフ**: COS法では確率密度の曲線、モンテカルロではヒストグラムで表示されます
- **それ以上になる確率グラフ（P(D≥x)）**: 横軸のダメージ x 以上になる確率（%）を表す曲線です。CDF を反転した値（1 − 累積確率）なので、目標ラインの高さがそのまま通過確率に対応します
- **赤い破線**: 期待値（平均ダメージ）
- **緑の実線**: 目標ダメージ（設定時のみ）。注記に通過確率が併記されます
- **通過確率**: 目標ダメージを超える確率がテキスト表示されます（末尾に COS法 / MC の別が付きます）
- **通過確率 ⇄ ダメージ 変換**: グラフの上・通過確率テキストの下にある変換パネルで、任意のダメージから通過確率（P(D≥x)）を、また任意の通過確率(%)から対応するダメージを、相互に計算できます。直近のシミュレーション結果（分布）に基づいて即座に更新されます。ダメージ欄はシミュレーション実行のたびに**目標ダメージ**が初期値として入力されます（その後は自由に書き換え可能で、次回実行時に再び目標ダメージへ戻ります）

## 8. 足切りライン最適化

複数のチェックポイントで**リセット（リスタ）する運用**において、各関門の**最適な足切りライン**を計算し、目標達成までのスループット（成功/時間）を最大化するページです。

各関門は「コスト/成功 = 期待時間/成功確率」を最小化する Bermudan 後ろ向き帰納で決定します（HP依存＝積モデル、HP依存＋通常の**混在モデル**にも対応。混在時はブロック集約グリッドDPで計算します）。

### 手順

1. **ダメージシミュレータ**ページで攻撃カードを設定する（足切りライン最適化はこの攻撃列を使います）。
2. ナビバーで「**足切りライン最適化**」に切り替える。
3. 「**カード読込 / 更新**」を押す（カードを変更したら都度押してください）。
4. 設定する：
   - **足切り（チェックポイント）の追加**: プルダウンから足切り判定を行う関門（カード）を選び「**+ 追加**」を押します（最終セグメントは候補に出ません）。
   - **区間カード**: 足切りで区切られた各区間が 1 枚のカードとして並びます（末尾は「完走」区間）。足切りを追加するとカードが分割され、各カードの「✕」でその足切りを解除できます。
   - **所要時間**: 各区間カードに、その区間を回すのにかかる時間を入力します。比だけが結果に影響するので、おおよその秒数で構いません。コスト = 期待時間 / 成功確率 の計算に使われます。
   - **🎲 ダメージ外 成功率%**: ダメージ（足切り）とは無関係な成功要因の確率。区間を回しきって次へ進める割合で、失敗するとリスタートします（その区間の所要時間は消費）。100% なら従来どおりダメージ足切りのみで判定します。
5. **目標ダメージ D** を入力する。
6. 「**解析実行**」を押す。

### 結果の見方

- **図**: チェックポイントごとの最適足切りライン（目標までの**残りダメージ**）。横軸は「足切り1, 2, …, 完走」。点にカーソルを合わせるとカード名と区間/累積通過率が表示されます。残り0の「完走/目標達成」行が末尾に自動追加されます。
- **サマリ**: 成功率 / 平均所要時間 / スループット（成功/時間）。「足切り無し」との比較で**時短率（speedup）**を表示します。
- **表**:
  - **区間通過率** = そのチェックポイントに到達した試行のうち足切りを通過する割合（条件付き）。
  - **累積通過率** = 開始からそこまで全関門を通過する割合。最終行（完走/目標達成）の累積が目標達成率です。

### リスタラインを手で調整して確率の変化を見る

「解析実行」の結果の下に、**リスタライン手動調整**パネル（青枠）が表示されます。

- 各足切りの「**残りダメージ**」**スライダー**が、最適ラインの値で初期表示されます。
- スライダーを動かすと、その足切りラインでの**成功率・平均時間・スループット（時短率）**が即座に再計算され、グラフに反映されます。
- グラフは **青＝あなたの設定ライン** と **灰点線＝最適ライン** を重ねて表示します。点にカーソルを合わせると区間/累積通過率が表示されます。
- サマリに**最適比**（成功率の差・スループット比）を表示するので、最適からどれだけ離れているかが分かります。
- 「**最適ラインに戻す**」ボタンで全スライダーを最適値へ戻せます。

足切りを**厳しく**（残りダメージを小さく）すると通過率が下がり、**緩く**すると通過率は上がるが時間を浪費します。スループット（成功/時間）が最大になる点が最適ラインです。

### 冗長な関門について

計算上の最適足切りライン（残りダメージ）は途中で**増加**することがあります（後続区間の所要時間が大きいほど、その手前の関門を厳しくするのが最適なため）。ただし関門を通過した後は累積ダメージが増えるだけなので、そのような関門は誰も足切りせず実質的に拘束していません。表示上は冗長な関門を手前の水準まで引き上げて**単調化**しており（足切り判定・通過率・スループットは不変）、区間通過率がほぼ100%の関門には「設定から外しても結果は変わりません」という注記が付きます。

## 9. スキル順探索(β版)

使いたいスキル順（手順）を満たす**開始スキル設定**（手札3枚＋山札3枚の初期配置）を全探索するページです。

### モデル

- カードは全6枚。3枚が手札（スロット1〜3）、3枚が山札（上から順）。
- カードを使うと山札の一番下へ行き、山札の一番上が同じスロットにドローされます。

### 手順

1. **カード設定**にキャラ名を6枚分入力します。複製スキル持ちには「複製スキル」をチェック。
2. **手順**に使いたいスキルを上から順に指定します。生徒を選ぶと自動で次の空行が追加されます（未選択の行は無視されます）。
   - **指定なし** = 繋ぎの1枚（何を使ってもよい）。ただし複製スキルの元カードは複製対象を決められないため使われません。
   - **枠**（手札スロット: 左・中・右）指定でそのステップの使用スロットを固定できます。
   - 各手順には**メモ**を書けます（探索結果の手順表示にも表示されます）。
3. 必要なら**手順間の制約**（別スロット / 同じスロット）を追加します。手順番号（1始まり）をカンマ区切りで指定します。裏にあるスキルの後掛けを回避したい場合などに設定してください。
4. **探索実行**を押すと、条件を満たす開始スキル設定と使用順の一覧が表示されます。

### 結果の見方

- **1〜5 の番号** = 開始スキル画面でカードをタップする順番。**黄 1〜3** = 手札（左から）、**青 4** = 山札の上・**青 5** = 山札の中です（ゲームの開始スキル画面と同じ色分け。6枚目=山札の下は残りの1枚で自動的に決まるため表示しません）。
- **使用順**の `[左]` `[中]` `[右]` は使用する手札スロットの位置です。

### 複製スキル

- 複製キャラ **A** の手順では**複製対象 B** を選択します。撃つとその場でカード A が「**B(コピー)**」に変化します（山札への移動・ドローは発生しません）。
- 「**B(コピー)**」を使う手順はドロップダウンで「B(コピー)」を選びます。使用するとカードは A に戻って山札の一番下へ行きます。

### ドローフラグ

そのステップでスキルカードのドローが発生する場合に「**ドロー**」をチェックします。

- 使用カードが山札の下へ行った後、**そのスキルの元カード**が山札にあれば、元々カードがあったスロットへ引き抜かれます（無ければ通常どおり山札の一番上をドロー）。
- 通常カードの場合は自分自身が山札に落ちた直後なので、必ず手札に戻ります（＝連打が可能になります）。
- コピーカードの場合は複製キャラのカードに戻って山札の底へ行き、**複製元のカード**が山札にあれば引き抜かれます。

## 10. 操作のヒント

- **カードの並び順**は実際の攻撃順に揃えてください。足切りライン最適化のチェックポイント位置は並び順（累積ヒット数）に依存します。
- 入力一式は **JSON で保存/読込**できます（セクション5）。
- 結果のグラフはPlotlyで描画されており、**ズーム・パン・ホバー**で詳細を確認できます。
- ダメージのレンジ・会心率などの元データは **[Schale DB](https://schaledb.com/)** のダメージ計算ツールで確認できます。
